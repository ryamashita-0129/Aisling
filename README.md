# Aisling

**AI がゲームマスターを務める、一人用テーブルトーク RPG ツール。**
世界・NPC・出来事をすべてファイルに記録しながら進めるので、何十セッション続けても設定や伏線を忘れません。持ち込んだ世界設定や自作キャラクターでも遊べます。

> 配布物は [Releases](../../releases) にあります。このリポジトリには README しか置いていません。

## ダウンロード

[Releases](../../releases/latest) の `Aisling-vX.Y.Z-win32-x64.zip` を落としてください。Windows 用で、Node.js などのインストールは不要です。必要なのは API キーだけです。

API キーは [Anthropic Console](https://console.anthropic.com/settings/keys)（`sk-ant-...`）または OpenAI のものが使えます。従量課金です。

現在は Windows 版のみ配布しています。

## はじめかた（Windows 版）

1. ZIP を好きな場所に展開する
2. `Aisling.exe` をダブルクリックする。初回は `.env` というファイルが作られてメモ帳で開くので、`ANTHROPIC_API_KEY=` の右にキーを貼って保存する
3. もう一度 `Aisling.exe` を起動する。ブラウザで GM の画面が開く
4. 「はじめよう」か「おまかせで始めて」と送る

黒いウィンドウは遊んでいる間は閉じないでください。終わるときはそのまま閉じて構いません。記録は毎ターン保存されます。

Windows に「発行元を確認できません」と言われたら、「詳細情報」→「実行」で起動できます（コード署名を付けていないためです）。

詳しい説明は ZIP 内の「はじめにお読みください.txt」にあります。

## できること

- **忘れない GM**: 状態（HP・所持品・場所・時刻）、出来事の記録、NPC や伏線のメモを GM 自身がファイルに書き、必要なときに検索して読みます。会話が長くなると自分で引き継ぎ要約を書いて記憶を整理するので、コンテキストの上限を気にせず続けられます。
- **世界設定は整理せずそのまま放り込める**: 画面の「資料」に、手持ちの設定書をそのまま貼るだけで使えます。何十万字あっても GM は毎回全部を読むのではなく、その場面に必要な節だけを検索して引いてきます。検索は語の一致だけでなく「意味」でも当たるので、「北門で会った衛兵の話」のような言い回しでも該当箇所が出てきます。この検索は同梱の小さな AI モデルが手元の PC の中だけで行い（GPU があれば使い、無ければ CPU）、設定も追加費用も要りません。
- **PC とハウスルールの持ち込み**: プレイヤーキャラクターを書いておけばキャラ作成を飛ばしてその設定で始まり、ハウスルールや前提は毎ターン GM に渡ります。
- **GM の人格を差し替え**: 語り口や進め方を書いた `gm.md` で GM をまるごと自分好みにできます。ダイスを振らない物語重視の遊び方にも対応します。
- **過去の出来事も引ける**: 出来事の記録、GM のメモ、過去の会話も同じ検索の対象です。「前に会ったあの商人」と言えば GM が記録から探します。
- **手元だけで動く**: サーバーは自分の PC の中だけで動き、API キーもキャンペーンの記録も展開したフォルダの外には出ません。フォルダごと消せばきれいに消えます。
- **モデルの切り替え**: Claude（既定）と OpenAI に対応。`.env` の設定で切り替えます。
- **画像生成（任意）**: NPC の肖像や場面の背景を OpenAI の画像モデルで作れます。画像ごとに課金されるため既定では OFF で、`.env` で明示したときだけ有効になります。

## 世界設定を持ち込むときのコツ

基本的には何もしなくて大丈夫です。あえて言うなら次の 2 点で、どちらも普通の設定書なら自然に満たしています。

- 見出し（`#` や `##`）で話題ごとに区切ってあると、その節が検索と引用の単位になります。1 節は数百字くらいが一番よく当たります（長い節は自動で分割されます）。
- 固有名詞の表記はなるべく揃えてください（「ブラム」と「Bram」が混在すると片方しか当たらないことがあります）。

大きな設定書を入れた直後は、裏で索引作りが数十秒〜1 分ほど走ります。その間もキーワード検索で遊べます。

## 費用の目安

既定のモデルは `claude-opus-5` です。安く遊びたい場合は `.env` に次を足してください（品質は十分です）。

```
AISLING_MODEL=claude-sonnet-5
```

Sonnet 5 で 1 ターンあたり 1 円未満〜数円程度が目安です（持ち込み資料の量や GM の作業量で変わります）。

## 記録の場所

すべて `campaigns/（キャンペーン名）/` の中です。

```
state.json    現在の状態          journal.md   出来事の記録
memories/     GM のメモ           summaries/   引き継ぎ要約
world/ pc.md  持ち込んだ資料      log.md       プレイログ（読み返し用）
```

## 困ったとき

- **認証エラー**: `.env` のキーを確認（前後の空白・改行・コピー漏れ）。保存後に起動し直す。
- **ブラウザが開かない**: 黒い画面に表示される `http://127.0.0.1:8787/` を手で開く。
- **ポートが使用中**: Aisling が既に起動していればそのブラウザ画面を開きます。別のプログラムが使っている場合は自動で次の番号を試します。固定したいときは `.env` に `AISLING_PORT=8790` のように書きます。
- **前の会話が消えた気がする**: 仕様です。GM は要約と記録から続けています。
- **すぐ閉じる・動きがおかしい**: `logs/aisling.log` に原因が残ります。Issue にはこのファイルを添えてください。

不具合や要望は [Issues](../../issues) へどうぞ。
